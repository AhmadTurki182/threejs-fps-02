IRONLINE — a round-based tactical FPS in the spirit of Counter-Strike, built with three.js: 3v3 Ember (attackers) vs Slate (defenders) on Ferroline Yard, plant/defuse the charge or eliminate the other team, economy between rounds to buy weapons, accuracy over speed. Round 4 elite pass: dusk-lit steel-town visuals (gradient sky, procedural ground, lit site beacons), soldier-model bots with distinct roles (assault, flanker, anchors, rear-guard), suppressive fire, hurt-retreat and pincer flanks, and restaged action screenshots; the simulation stays real-time on a decoupled fixed-step sim.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8000 in a browser. Static files only, no build step, no network — three.js is vendored under `game/vendor/three/`.
